# 個人用食事記録アプリ 費用・工数内訳

状態：v1.1。「開発費用・工費」は、初期開発費、工程別工数、月額運用費に分けて整理する。発注見積・請求書ではない。

## 1. 運用費用と既存AI契約の利用（2026-09-22確認）

### 費用が発生する箇所

| 項目 | 無料を優先する方針 | 課金・制限の要因 |
|---|---|---|
| AI解析 | Gemini API無料枠を採用。上限時は手入力 | 解析回数、画像・文章の入力量、出力量。無料枠の対象・上限がある。有料モデル・検索機能を自動で有効化しない[^2] |
| アプリ公開 | 個人用途の無料枠を候補とする。Vercel Hobbyは候補の一例であり採用未確定[^4] | 実行時間・通信量などの無料枠。独自ドメイン購入は初版不要 |
| データ・写真・認証 | 無料枠のDB/Storage/Authを候補とする | Supabase Freeの例ではDB500MB・ファイル1GB。非稼働1週間で停止、無料の自動バックアップなし。採用未確定[^5] |
| Obsidian取り込み | 所有PCで動く同期処理を想定。新しい同期サブスクの契約を前提にしない | PCが動いていない間は取り込みが遅延。既存の通信・電気・保存容量は別 |

月額0円を設計目標とするが、無料枠の利用資格・空き容量・実際の解析回数を確認するまで運用0円を保証しない。無料枠に近づいたら通知し、有料契約・自動課金切り替えは行わない。

写真の容量試算例（仮定）：1枚300KBまで縮小し1日5枚なら約45MB/月、約540MB/年。1GBの枠は無期限保存には不足するため、実画像で品質を確かめ、容量表示・全画像バックアップ・容量不足時の保存前案内を設ける。自動削除は未承認であり行わない。

### 既存のChatGPT・Geminiを使う方法

- ChatGPTの月額契約とAPIは別課金。ChatGPTに加入しているだけで独自アプリからのAPI呼び出しが無料になるわけではない。[^1]
- Gemini APIはAPI用の無料/有料枠とCloud Billingで管理される。今回、ユーザーのGemini契約プラン・API特典は確認しておらず、既存契約にAPIが含まれるとは断定しない。[^2]
- 既存チャットを使う代替設計：アプリで解析依頼文をコピー → 本人がChatGPT/Geminiで写真を解析 → 所定JSONをアプリへ貼り付け → 検証・確認して保存。追加APIを使わないが、アプリ間の切り替えと貼り付けが必要。これは機能案であり実装未検証。
- 無料API案（採用）：料理部分だけを解析に送り、本人の氏名・位置情報・健康プロフィール・食事履歴全体を送らない。無料サービスでは入力/出力が製品改善や人によるレビューに使われ得る。規約は個人情報・機密情報等を送らないよう求めているため、顔や個人情報の写り込みは送信対象から外す。データ利用条件はユーザー了承済み。[^3]
- どちらを選んでも定型メニュー追加はAI不要。新規解析と区別する。


## 2. 初期開発費と工程別工数

新規外注・有料サービス購入は未発注。既存AI契約費とは区別し、本アプリ専用の追加開発費は未確定。下記は今回の範囲を人が実装・検証する場合の計画用概算であり、AIの実行時間・納期を保証しない。

| 工程 | 作業範囲 | 参考工数 |
|---|---|---|
| 要件・設計 | 7栄養項目、目標履歴、画面・データ設計 | 3〜5時間 |
| スマホUI | 入力・日計・履歴・定型・設定 | 6〜10時間 |
| 保存・認証 | 本人限定、DB、画像、容量管理 | 4〜7時間 |
| AI解析 | 無料API、構造化検証、エラー・手入力 | 4〜7時間 |
| 目標・集計 | 7項目、適用日/revision、比率入力 | 3〜5時間 |
| 可搬性・同期 | CSV/JSON、復元、画像、Obsidian同期 | 5〜8時間 |
| 検証・公開準備 | iPhone、権限、日付境界、復元、本番構成 | 5〜8時間 |
| 小計 | 基本作業 | 30〜50時間 |
| 予備 | 無料枠・認証設定・端末固有問題 | 6〜10時間 |
| 合計 | 計画用概算 | 36〜60時間 |

- 工費の金額 = 合意した時間単価 × 対象工数。単価・委託先・請求条件は未設定のため金額は未算定。
- 作業量の参考であり、課金承認・請求・実作業時間・実支払額を意味しない。
- 目標履歴・糖質/食物繊維・復元は上記に含む。既存アプリからのデータ移行、完全オフライン、医療助言、複数人共有は含まない。
- 方針変更が必要でも自動契約せず、費用影響を先に示す。

## 3. 見積条件

- iPhone、1日3〜5回の新規解析、写真保存、1ユーザーを想定。
- 月額0円が設計目標。利用アカウントとモデルの無料枠確認前に回数を保証しない。
- API上限時は手入力/定型登録、画像容量上限時は案内して文章記録を選択可能とする。自動課金・写真の自動削除なし。
- 公開先/DBの最終採用、無料枠の空き、画像圧縮後の容量が決まった時点で更新する。
