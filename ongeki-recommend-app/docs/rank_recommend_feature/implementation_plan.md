# ランク目標リコメンド機能（SS→SSS / SSS→SSS+）の実装計画

ユーザーのテクニカルスコアランク更新（SS→SSS、SSS→SSS+など）を効率的に目指せるよう、**定数13.7以上**の楽曲に絞った「ランク目標リコメンド機能」を追加します。

---

## ユーザーレビューが必要な事項

> [!IMPORTANT]
> - **対象定数範囲**: 今回ご指示いただいた通り「**定数13.7以上**」の楽曲に限定します。
> - **目標ランクの定義**:
>   - **SS → SSS**: 目標スコア **1,000,000点**（現状スコア < 1,000,000 の曲、特に 990,000点以上を優先提示）
>   - **SSS → SSS+**: 目標スコア **1,007,500点**（現状スコア 1,000,000点以上 ～ 1,007,500点未満の曲）
> - **優先度の指標**:
>   - 「同レート帯（または格上）の他ユーザーの該当ランク達成率（%）」と「自分の現在スコアから目標までの差（あと何点か）」を計算し、達成しやすいおすすめ曲順にソートして提示します。

---

## 変更内容の概要

### 1. [backend] リコメンドエンジンの拡張
#### [MODIFY] [recommend_engine.py](file:///c:/Users/takahiro/Documents/OngekiRecommendApp/backend/recommend_engine.py)
- 定数 `13.7` 以上の楽曲を対象に、母集団ユーザーの SSS達成率 (TS >= 1,000,000) および SSS+達成率 (TS >= 1,007,500) を集計するロジックを追加。
- ターゲットユーザーの現状スコアに応じて、以下の2つのリストを生成して返却データに含める：
  - `rec_rank_sss`: 定数 >= 13.7、現状 TS < 1,000,000 の楽曲（他ユーザーの SSS達成率 と あと何点届くか を提示）
  - `rec_rank_sssp`: 定数 >= 13.7、1,000,000 <= 現状 TS < 1,007,500 の楽曲（他ユーザーの SSS+達成率 と あと何点届くか を提示）

---

### 2. [frontend] UIへのランク目標タブ・テーブルの追加
#### [MODIFY] [App.tsx](file:///c:/Users/takahiro/Documents/OngekiRecommendApp/frontend/src/App.tsx)
- 型定義 (`RecommendItem`, `GroupResult`) にランク目標用のプロパティ（`achievement_rate`, `diff_to_target`, `target_rank`）を追加。
- メインナビゲーションに **「ランク目標」** タブを追加。
- ランク目標タブ選択時にサブ切替ボタン **[SS → SSS (100万)]** / **[SSS → SSS+ (100.75万)]** を表示。
- テーブルに以下の項目を表示：
  - タイトル / 難易度 / 定数
  - 現状スコア & 現状ランク
  - 目標スコア (1,000,000 / 1,007,500)
  - 目標まであと (例: `あと 2,350 点`)
  - 他ユーザー達成率 (例: `45.2%` + ゲージ表示)

#### [MODIFY] [ExportControls.tsx](file:///c:/Users/takahiro/Documents/OngekiRecommendApp/frontend/src/ExportControls.tsx)
- 新しく追加されるランク目標タブのデータに対応したPNG画像/PDF出力のタイトルラベル設定を追加。
