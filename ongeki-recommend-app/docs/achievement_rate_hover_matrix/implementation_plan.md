# 楽曲別達成率マトリックス・ホバー表示機能の実装計画

「目標達成」タブの各楽曲レコードにマウスオーバー（ホバー）した際、その楽曲における**比較対象レート帯別の達成率マトリックス表**（縦軸: 比較対象レート帯、横軸: SS / SSS / FC / AB）をポップアップ表示する機能を追加します。

---

## 画面イメージ・表示仕様

### 💡 マウスオーバー時のポップアップカード表示

レコードにカーソルを合わせると、以下のようなマトリックス表がツールチップ/カード形式で即座に表示されます：

#### 🎵 「曲名」の達成率マトリックス
| 比較対象 | SS (99万+) | SSS (100万+) | FC (フルコン) | AB (全Break) |
|---|:---:|:---:|:---:|:---:|
| **±0.25 (同格)** | 85.2% | 45.0% | 60.1% | 20.5% |
| **±0.50 (周辺)** | 88.0% | 50.2% | 65.0% | 25.0% |
| **+0.50 (格上)** | 95.0% | 72.5% | 80.0% | 40.2% |

> [!TIP]
> 達成率に応じたカラーハイライト（高い達成率は緑、標準は青など）を付けて視認性を向上させます。

## 変更内容の概要

### 1. [backend] リコメンドエンジンの拡張
#### [MODIFY] [recommend_engine.py](file:///c:/Users/takahiro/Documents/OngekiRecommendApp/backend/recommend_engine.py)
- `analyze_group` または `analyze` メソッドにおいて、3つの比較グループ (`±0.25`, `±0.50`, `+0.50`) における各楽曲の `SS達成率`, `SSS達成率`, `FC達成率`, `AB達成率` を集計。
- 各目標楽曲オブジェクトに `rate_matrix` プロパティを持たせてレスポンスデータに含める。

---

### 2. [frontend] ホバー表示UIの実装
#### [MODIFY] [App.tsx](file:///c:/Users/takahiro/Documents/OngekiRecommendApp/frontend/src/App.tsx)
- `RecommendItem` 型定義に `rate_matrix` プロパティを追加。
- 目標達成タブのテーブル行（またはタイトル部分）にホバー時のポップアップツールチップコンポーネントを組み込み。
- カーソル位置・テーブル位置に合わせて画面外にはみ出さないスタイリッシュなツールチップカード（Tailwind CSS）を描画。

## 検証計画

### 1. バックエンド計算テスト
- `python backend/recommend_engine.py` を実行し、生成される JSON データ内に全目標曲の `rate_matrix` （3グループ × 4指標）が正しく含まれているか確認。

### 2. フロントエンド表示・動作確認
- `npm run build` でビルドテストを実行。
- ブラウザで「目標達成」タブのレコードにマウスオーバーし、ポップアップ表が滑らかに表示され、数値（SS/SSS/FC/AB達成率）が正確に表示されることを確認。
