# Ongeki Recommend App

オンゲキ（Re:Fresh対応）のスコアデータを分析し、あなたに最適な「目標スコア」や「次に狙うべき稼ぎ曲（逆リコメンド）」を提案してくれるツールです。

---

## 必要なもの（前提環境）
このアプリを動かすには **Python** が必要です。
PCにPython（バージョン3.10以上推奨）がインストールされていない場合は、以下の公式ページまたはMicrosoft Storeからインストールしてください。

- **Python 公式サイト**: https://www.python.org/downloads/
  - ※インストール時、最初の画面で **「Add Python to PATH」** というチェックボックスに必ずチェックを入れてください！

※ Node.jsなどのフロントエンド開発環境は不要です。すぐに遊べるようにビルド済みのデータを同梱しています。

---

## 起動方法

1. フォルダの中にある **`start.bat`** をダブルクリックして実行してください。
2. **初回起動時のみ**、自動的に必要な裏側の仕組み（ライブラリなど）をダウンロード＆インストールするため、数分ほど黒い画面のまま待ちます。
3. 準備が完了すると、自動的にブラウザが開いて `http://localhost:8000` の画面が表示されます。
4. 画面の入力欄に自分のオンゲキユーザーID（例: 10605）を入力し、「検索」ボタンを押してください。

※ 遊び終わったら、開いている「黒い画面（コマンドプロンプト）」の右上の×ボタンを押して閉じれば、アプリは完全に終了します。

---

## 機能の紹介

- **新曲枠・ベスト枠・PS枠の確認**: あなたのスコアを基に、あと少しでレートが伸びそうな曲を計算して目標スコアを提示します。
- **逆リコメンド (Weapons)**: 他の高レートプレイヤーがあまりやっていないのに、あなたが稼げている「隠れた武器曲」を探し出します。
- **他ユーザーデータ更新**: 逆リコメンドの精度を上げるために、ボタン一つで最新の高レートプレイヤー（母集団）のデータを自動収集することができます。
- **画像ダウンロード**: リストをPNG画像として保存し、X（旧Twitter）などで簡単に共有できます。

---

## トラブルシューティング
- **「Pythonがインストールされていないか、パスが通っていません」と表示される場合**:
  Pythonが正しくインストールされていないか、インストール時に「Add Python to PATH」のチェックを忘れています。一度Pythonを再インストールしてみてください。
- **画面が真っ白になる、または「サーバーへの接続に失敗しました」と出る場合**:
  黒い画面（コマンドプロンプト）が裏で開いているか確認してください。閉じてしまった場合はもう一度 `start.bat` を実行してください。
