# OPI (Ongeki Power Indicator) 開発記録

## プロジェクト概要
オンゲキのクリアランク達成難易度を定量化し、プレイヤーの適正実力（総合OPI）の算出、目標楽曲のリコメンド、およびレーティングとOPIの分布統計を行うアプリケーション。

## 環境情報

- **言語**: Python 3.x
- **主要ライブラリ**: `aiohttp`, `beautifulsoup4`, `pandas`, `scipy`, `matplotlib`, `SQLAlchemy`

- （任意）UIのさらなるリッチ化やフィルタリング項目の拡充。
- **クローラー要件**:

  - 次回以降は前回実行時の最終更新日時を保持し、それ以降のデータのみを差分取得することで時間短縮を図る。
- **データ解析**:
  - OPIの基準は定数14.0のSSSを1500にアンカーし、2母数ロジスティックモデルによる最尤推定を行う。
