オンゲキの実力指標「OPI」Webアプリケーション（Streamlit）の改修プロジェクト。新5段階ランク（S〜AB+）への完全対応、リコメンド機能の高度化、OPI難易度表のグリッド表示化、および達成状況を可視化する「マイOPI難易度表」の追加実装を行う。

Working directory: C:\Users\lyoul\AI_Project\90_Git\OPI_Project
Integrity mode: development

## Requirements

### R1. 新5段階ランク（S, SS, SSS, SSS+, AB+）への対応
- UI上の表記や内部の集計ロジックに残る旧ランク（SSS+ABFB, AP）を、新しい5段階（S, SS, SSS, SSS+, AB+）に完全に置き換える。
- ※バックエンドのDBマイグレーションは完了済みのため、主にフロントエンド表示とアプリ内クエリの修正となる。

### R2. リコメンド機能のUI高度化
- レベル（14, 14+, 15等）、現在ランク、目標ランクを「複数選択（マルチセレクト）」可能にする。未選択時は全対象を表示する。
- 目標達成確率の絞り込み条件として、従来の固定値ではなく「0〜100%の範囲スライダー」を設置し、表記を「勝率」から「クリア割合」に変更する。

### R3. OPI難易度表のグリッド化と「マイOPI難易度表」の実装
- 難易度表を100 OPIごとの帯域（例: 1500帯, 1600帯）で区切ったグリッド形式（表形式）にし、難しい曲（OPIが高い曲）ほど上に表示されるよう降順ソートを徹底する。
- 通常の難易度表とは別に「マイOPI難易度表」ビュー（またはタブ）を追加し、選択したユーザーがすでに目標ランクを達成済みの楽曲セルを色付きで塗りつぶし、未達成の曲と視覚的に区別できるようにする。

### R4. 統計・分布図の動的グラフ化
- 横軸をレーティング生値、縦軸を総合OPIとした散布図をStreamlit上に動的グラフ（Plotly等）として実装し、選択したユーザーの現在位置をハイライト表示できるようにする。

### R5. 作業フェーズごとのトークン・リソース管理
- 各フェーズ（機能ごとの実装区切り等）の終了時点でLLMの残り使用量（またはリソース状況）を確認する。
- 残り残量が20%以下の場合は、進捗状況をまとめた引き継ぎ書（handoff_document）を作成し、安全に作業を中断・終了すること。

## Acceptance Criteria

### アプリケーションの稼働とUI操作
- [ ] `streamlit run app.py` 等でアプリケーションがエラーなく起動すること。
- [ ] 「クリア割合」の0〜100%スライダー、およびレベル・ランクの複数選択UIが正常に動作し、結果が正しくフィルタリングされること。

### 難易度表と達成状況の可視化
- [ ] OPI難易度表が100単位のグリッドで降順表示されていること。
- [ ] 「マイOPI難易度表」において、ユーザーが達成済みの楽曲セルが正しく色付けされ、未達成曲と明確に区別できること。

### グラフ表示とリソース管理
