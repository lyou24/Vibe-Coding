# 修正内容の確認 (Walkthrough): マイデータレベル別達成状況の表表示の修正

ユーザー様のご要望に基づき、難易度切替ボタンを削除し、不確実な全曲データベースの分母表示（`/ 345` 等）を取りやめて、**「ユーザーが実際にプレイした純粋な譜面数 (`288 譜面` 等)」** をシンプルかつ正確に表示するよう修正しました。

---

## 修正内容

1. **難易度フィルター切り替えボタンの削除**
   - 不要な難易度切替ボタンを UI から削除しました。

2. **レベル別表の列表示のシンプル化**
   - **変更前**: `プレイ状況 (走破率)` にて `288 / 345 83.5%` のように、全難易度・削除曲等の曖昧な分母を表示して誤解を生んでいた問題を解消。
   - **変更後**: **「プレイ譜面数 (例: `288 譜面`)」** に表示を変更。各レベル帯においてユーザーがプレイした譜面数のみを表示し、SSS/FC等の達成率はそのプレイ済譜面数を100%とした正確な達成割合を表示。

3. **クリアランプ達成分布における ALL BREAK+ (`AB+`) 集計ロジックの再定義**
   - **定義**: オンゲキにおける `ALL BREAK+` (`AB+`) は Full Bell + All Break のランプ文字列表記ではなく、**理論値スコア（`1,010,000` 点）達成**を指します。
   - **修正内容**: `backend/recommend_engine.py` の `compute_my_data_stats()` および `calc_ts_rating()` において、スコアが `1,010,000` 点以上（`ts >= 1010000`）の演奏を `ALL BREAK+` (`AB+`) として判定・集計するよう修正しました。スコアが `1,010,000` 未満の All Break 達成曲は `ALL BREAK` (`AB`) としてカウントされます。

4. **レベル別達成状況における Lv 10〜11+ および Lunatic 行の非表示化**
   - **変更内容**: 参照される頻度が低い `Lv 10`, `Lv 10+`, `Lv 11`, `Lv 11+` をレベル別達成状況の表から非表示にしました。また、`Lunatic` 難易度の楽曲は独立した行としては置かず、本来の各レベル数値帯（`13+`, `14`, `14+` 等）に含めて集計・表示します。表には `Lv 12` から `Lv 15` までの数値レベル帯のみが表示されます。
